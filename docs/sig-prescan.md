# ColdHook Signature Prescan — идея (набросок)

Цель: хукать **стрипнутые внутренние функции** стабильно — там, где `name` не существует, а
сырой `HOOK_ADDR(off)` гниёт на каждом апдейте. Решение — **сигнатурный прегенератор на хосте**:
сканируем `__text` цели на этапе merge, резолвим сигнатуру → `vmaddr`, и кормим адрес в уже
существующий by-address путь. Не реализация, а план (как `swift-dsl.md`).

## Главный принцип: host-side, на этапе merge — ядро не трогаем

ColdHook резолвит всё **офлайн**, а не в рантайме. Значит сигскан — это не in-process сканер
(как у Substrate/Frida), а ещё один **резолвер адреса в оркестраторе**.

```
sigs.toml  →  оркестратор сканирует __text цели  →  sig → vmaddr  →  существующий HOOK_ADDR
```

Сигнатура превращается в адрес **до** того, как мёрджер что-либо увидит. Мёрджер остаётся
тупым (имена + адреса). Swift-ядро (`vendor/MachOMerger`) **не меняется вообще** — вся логика в
Python (`coldhook/`), который и так парсит цель для `info`.

## Ниша (когда брать)

Приоритет адресации: **`name` → `sig` → сырой `addr`**.

| Способ | Когда | Стабильность |
|---|---|---|
| `HOOK(name)` | символ есть (экспорт/ObjC/несрипнут) | высокая, нативная |
| `HOOK_SIG("...")` | **стрипнутая внутренняя функция** | средняя, переживает апдейты при масках/якорях |
| `HOOK_ADDR(off)` | быстрый эксперимент / последний шанс | нулевая (рот на каждом билде) |

Для экспортов и ObjC сигскан НЕ нужен — там `name` дешевле и нативнее.

## Как выглядит

Сигнатуры — сайдкар `sigs.toml` (данные, не код → переезолвятся при каждом merge):

```toml
[sig.crypto_check]
# masked words: каждая строка — инструкция, '.' = wildcard-ниббл (имми/регистры)
pattern = [
  "ff 43 01 d1",     # sub sp, sp, #0x50      (точный)
  ".. .. .. 94",     # bl <любой>             (опкод фиксирован, цель wild)
  "e0 03 1f aa",     # mov x0, xzr
]

[sig.real_handler]
# якорь: найти xref на строку, шагнуть на функцию-владельца
anchor = { string = "license invalid", walk = "owner" }
```

В коде/конфиге хук ссылается на имя сигнатуры:

```c
HOOK_SIG("crypto_check", my_crypto_check)   // макрос-обёртка над by-address
```

Оркестратор резолвит `crypto_check → 0xNNNN` и разворачивает в обычный
`_COLDHOOK_ADDR_<hex>` — дальше путь идентичен `HOOK_ADDR`.

## Формат сигнатур (ARM64)

Байтовые IDA-паттерны под ARM64 неудобны: инструкции 4-байтовые, изменчивые биты
(регистры/имми) размазаны по битфилдам. Примитив — **masked words**: пары `(word, mask)`,
матч по `instr & mask == pattern & mask`. Маской зануляем имми/регистры → переживает
перетасовку регистров и сдвиг адресов.

**Anchor walks** — настоящая стабильность через версии (якоримся за смысл, не за байты):

- `@call` — сматчил `bl`/`b`, декодируешь `imm26`, `+PC` → адрес реальной цели;
- `@adrp_add` — нашёл `adrp/add` (или `adrp/ldr`) на строку/данные → xref → функция-владелец;
- `@b` — относительный переход.

Якорь через уникальную строку переживает даже рефактор тела функции.

## Как работает (pipeline)

```
1. читаем sigs.toml  ->  список {name, pattern|anchor, walk?}

2. достаём __TEXT,__text цели (байты + базовый vmaddr секции)
   + при anchor=string: __TEXT,__cstring и таблицу xref'ов (скан adrp/add)

3. для каждой сигнатуры:
   - masked-scan по __text шагом 4 байта
   - anchor-walk: декод bl/adrp+add -> вычислить целевой адрес
   - file-offset матча -> vmaddr  (учесть базу слайса; FAT уже тонко режем)

4. ВЕРИФИКАЦИЯ (киллер-фича): матчей != 1 -> падаем на этапе сборки
   - 0 матчей  -> "sig 'crypto_check' не найдена (цель сменилась?)"
   - >1 матч   -> "sig 'crypto_check' неоднозначна (N мест): 0x.., 0x.."
   - кросс-чек: если по адресу ЕСТЬ символ в symtab -> печатаем (санити)
   - dump дизасма вокруг матча для глаз (otool -tV @addr)

5. name -> vmaddr  =>  тот же _COLDHOOK_ADDR_<hex>, что и HOOK_ADDR
```

`fail-loud на этапе merge` — главное преимущество перед рантайм-сканом: ambiguous/missing ловится
в `make`/`merge`, а не молчаливым хватанием не того адреса и крэшем в чужом процессе.

## `coldhook siggen` — авто-генерация сигнатур

Чтобы авторинг был дешёвым: по **референс-билду с символами** генерим сигу для цели.

```
coldhook siggen <ref-binary> <symbol|0xaddr> [--len N] [--anchor]
```

1. берём N инструкций со входа функции (дефолт 6–8);
2. **маскируем** изменчивые поля: `bl/b` цель, `adrp/add/ldr` имми, иногда регистры;
3. проверяем **уникальность** в этом же бинаре (иначе расширяем окно / добавляем якорь);
4. при `--anchor` — ищем рядом xref на строку, эмитим anchor-форму (стабильнее);
5. печатаем готовый `[sig.<name>]`-блок для `sigs.toml`.

Референс — твой RE-билд или старая символикованная версия; сига переживает апдейты, пока форма
кода стабильна.

## Что переиспользуется / что новое

| Уже есть | Новое для sig-prescan |
|---|---|
| by-address путь, магик-символ `_COLDHOOK_ADDR_<hex>` | резолвер `sig → vmaddr` в оркестраторе |
| `coldhook/macho.py` (inspect, slice, FAT-тонко) | чтение байтов `__text`/`__cstring` (otool -s / парс LC) |
| `coldhook info` парсит цель | masked-scanner + ARM64-декодер `bl`/`adrp+add` для anchor-walk |
| `HOOK_ADDR` макрос в `coldhook.h` | `HOOK_SIG("name", fn)` (тонкая обёртка) + парсер `sigs.toml` |
| `cmd_*` в `cli.py` | подкоманды `siggen` и `sigscan` (dry-run: показать резолв без merge) |

## Открытые вопросы

- **Где читать байты секции.** `macho.py` сейчас идёт через otool/nm (`_run`), не парсит LC сам.
  Для скана нужен сырой `__text`: либо `otool -s __TEXT __text` (текстовый дамп → парс), либо
  мини-ридер load-commands. Склоняюсь к мини-ридеру (точные file/vm-оффсеты для anchor-walk).
- **ARM64-декодер.** Нужен минимальный: `b`/`bl` (imm26), `adrp`+`add`/`ldr` (page+lo12 для
  string xref). Полный дизасм не нужен — только эти формы для якорей.
- **arm64e / PAC.** Указатели в данных подписаны; для скана **кода** PAC не мешает (имми в
  инструкциях не подписаны). xref через `adrp/add` тоже чистый. Auth трогаем только если якорь
  идёт через `__got` (отложить).
- **Кэш резолва.** Сига → адрес можно кэшировать по (uuid-цели, имя-сиги), чтобы повторный merge
  не рескан­ил. Инвалидация по UUID Mach-O.
- **Versioned sigs.** Возможность держать несколько паттернов под одно имя с дискриминатором по
  версии/UUID цели — выбирать подходящий. На будущее.
- **`sigscan` как самостоятельная команда** — прогнать `sigs.toml` против бинаря и показать
  таблицу `name → addr (+символ если есть)` без merge. Дёшево, помогает отлаживать сиги.
